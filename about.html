What is Excuse.exe?

Excuse.exe is a fun web project created to generate creative excuses for everyday situations. It's mainly designed for entertainment and learning — pick a situation, pick a style, and get a ready-made excuse in seconds.

Everything runs locally in your browser: the excuse database is a set of hand-written JavaScript arrays, ratings are generated on the fly, and anything you save lives in your browser's storage. No accounts, no server, no external AI API required for this version.

Built for fun. Built with care. Built to make you laugh. 😂

Under the hood

FRONTEND

HTML, CSS, and vanilla JavaScript — no build step, no framework, just open it in a browser.

DATA

50+ hand-written excuses organized by situation and style, kept in data/excuses.json and mirrored inline in script.js.

STORAGE

Saved excuses use localStorage — nothing leaves your device.

FUTURE

Designed so a Python Flask API can later slot in behind an /api/generate endpoint. See the README for the plan.

Content policy

Every excuse in the database is written to be harmless and silly. Nothing here is meant to encourage dishonesty that causes real harm, cover up serious problems, or suggest anything dangerous or illegal — it's a joke generator for small everyday moments, not a tool for getting out of anything that actually matters.
